# Rock Paper Scissor game

## Description
This is a simple rock paper scissor game built using HTML, CSS and JavaScript

## Features
- Play against computer
- Random computer choices
- Live score update
- Instant result display

## Technologies used
- HTML
- CSS
- JavaScript
- Git(version-control)

## Tools used
- VScode
- GitHub
- Netlify(for hosting and domain)
